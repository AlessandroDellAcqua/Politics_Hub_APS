Politics Hub Pannello admin

Accesso

Il pannello scrive direttamente nel repository GitHub del sito. Serve un token personale (fine-grained) con permesso Contents: Read and write sul solo repository del sito. Il token resta salvato solo su questo computer.

Come crearlo: GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token → Repository access: solo il repo del sito → Permissions → Contents: Read and write.
